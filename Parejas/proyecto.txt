Tablas:
    Partida(
        ID,
        Usuario_ID,
        Casillas(Numero de casillas total)
        Estado(Activa,perdida,ganada),
        Intentos
    )
    Usuario(
        ID,
        Username,
        Password
    )
    Casilla(
        ID,
        Partida_ID,
        NumeroContenido(El numero que tendra esta casilla),
        PosicionEnTablero,
        DestapadaPermanente(un boolean que sea true cuando acierte y eso sea lo que compruebe una funcion para mostrarlas o no)
    )

Ideas:
    Mostrar un array(auxiliar) vacio al Usuario, si acierta,cambiar esos huecos por el numero en concreto permanentemente, si falla volver a ponerlos vacios.


Rutas:

    GET:
        /partida/{id} (Coge una partida si es el Usuario correcto, por body)
        /partida (te devuelve tus partidas, con body del usuario por json)
    POST:
        /partida (Crea una partida con tu usuario por body)
        /destapar/{num1}/{num2} (partida_id y Usuario_ID por body, para poder hacer control de errores por ruta)
    PATCH:
        /rendirse? (por si el usuario quiere abandonar la partida, id_usuario, id_partida por body)
